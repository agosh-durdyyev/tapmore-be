# TapMore backend

Backend repository for TapMore. No API server is implemented yet.

## Related repositories

- [Landing page and signup-free preview](https://github.com/agosh-durdyyev/tapmore-fe)
- [Dashboard and page editor](https://github.com/agosh-durdyyev/tapmore-dashboard)

The current frontend prototypes save drafts in the browser. They do not yet call a backend or publish public user profiles.

## Planned responsibilities

- User authentication and account access.
- Username availability and reservation.
- Profile and link storage with per-user authorization.
- Publishing public profiles and managing custom domains.
- Validated analytics ingestion and abuse controls.

The runtime, database, authentication provider, and API contract remain to be selected before implementation.
